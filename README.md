To-Do List App - ngit_frontend_week_13

A simple, responsive To-Do List application built with HTML, CSS, and Vanilla JavaScript.

Live Demo:https://luciasoladoye.github.io/ngit_frontend_week_13/

Features
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Filter tasks (All / Active / Completed)
- Clear completed tasks
- Local storage persistence
- Mobile responsive

How to Run
1. Clone the repository:
   `git clone https://github.com/LuciaSoladoye/ngit_frontend_week_13.git`
2. Open `index.html` in your browser
3. Start adding tasks!

Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
- LocalStorage API
